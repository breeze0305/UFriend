FFmpeg 8.1.2-ufriend1, Windows x64, built for UFriend.
This is a UFriend build from upstream source, not a Gyan binary.
FFmpeg and its selected libraries are statically linked; only Windows system DLLs are required.
Includes libass with DirectWrite/GDI, FreeType, FriBidi, HarfBuzz, x264, and LAME.
FFmpeg native codecs, containers, and filters remain enabled; AAC uses FFmpeg's native encoder.
No external TLS, network protocols, fontconfig, or optional hardware SDKs are enabled.
