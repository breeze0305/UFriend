# FFmpeg 8.1.2-ufriend1 對應來源

[English](SOURCES.md) | [繁體中文](SOURCES.zh-TW.md)

請從與此 runtime 相同的發布版本下載 `FFmpeg-8.1.2-ufriend1-corresponding-source.tar.xz`。

封包包含 `sources/`（實際使用且通過 SHA-256 驗證的輸入封包）、`recipe/`、`configuration/` 與 `licenses/`。`SOURCE_INVENTORY.json` 列出所有選用的函式庫。請參閱 `recipe/README.md`，在不重新下載這些輸入的情況下重建。

此建置不使用第三方二進位函式庫。未修改的編譯器／建置工具與 Windows 系統函式庫不包含在此應用程式的來源封包中；封包內包含實際安裝的確切編譯器版本，以及編譯器／runtime 聲明。
