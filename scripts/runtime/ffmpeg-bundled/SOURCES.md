# FFmpeg 8.1.2-ufriend1 corresponding source

Download `FFmpeg-8.1.2-ufriend1-corresponding-source.tar.xz` from the same release as this runtime.

The archive contains `sources/` (the actual SHA-256-verified input archives), `recipe/`, `configuration/`, and `licenses/`. `SOURCE_INVENTORY.json` identifies every selected library. See `recipe/README.md` to rebuild without downloading those inputs again.

The build does not use third-party binary libraries. The unmodified compiler/build tools and Windows system libraries are outside this application's source bundle; exact installed compiler versions and compiler/runtime notices are included.
